> 더 나은 약품 정보를 위한 약품 검색 플랫폼, YAK+

## 📖 프로젝트 소개

현대인의 건강 관리에 있어 올바른 약품 선택과 정보 탐색의 중요성이 날로 높아지고 있습니다.  
그러나 대부분의 약품 정보 플랫폼은 방대한 데이터 속에서 직관적인 정보 제공을 충분히 지원하지 못해,  
실제 건강 문제에 즉각 대응하기 어려운 상황입니다.  
<br/>  

### YAK+ 는 다음과 같은 상황에서 도움을 드립니다:

- 어떤 약을 골라야 할지 막막할 때
- 생각한 증상에 맞는 약품을 찾고 싶을 때
- 같은 성분을 가진 비슷한 약을 찾고싶을 때
<br/>

## 주요 기능  
<div align="center">
<img src="https://github.com/user-attachments/assets/97fbd0cc-10a0-4db0-aee2-146005861e0e" width=800 />
</div>

- ### 키워드 기반 검색  
  - 약품명, 성분명, 증상명 등 특정 키워드를 입력하여 즉시 검색 결과를 확인할 수 있습니다.  
  - 사용자의 입력을 기반으로 검색어 자동완성을 지원합니다.
- ### 자연어 증상 검색  
  - “상처가 따끔거려요”, “콧물이 흐르고 기침을 해요” 등 사용자가 입력한 자연어 증상 설명을 분석하여 관련 약품을 검색합니다.
- ### 약품 상세 정보 조회  
    - 검색한 약품의 상세 정보를 확인할 수 있습니다.
